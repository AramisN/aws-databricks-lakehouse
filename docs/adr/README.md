# Architecture Decision Records

This directory tracks Architecture Decision Records (ADRs) for the aws-databricks-lakehouse
project. Each ADR captures a significant architectural decision, the context that drove it, and
its consequences.

## Creating a new ADR

1. Copy [template.md](template.md) to `NNNN-short-title.md`, using the next sequential number.
2. Fill in the sections and set the status (`Proposed`, `Accepted`, `Deprecated`, or `Superseded`).
3. Open a PR for review.
