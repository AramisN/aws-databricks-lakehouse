# Contributing

Contributions, suggestions, and improvements are welcome.

## How to contribute

1. Fork the repository.
2. Create a feature branch:
   `git checkout -b feature/your-feature`
3. Make your changes.
4. Test your changes locally.
5. Commit your changes with a clear commit message.
6. Open a pull request against the `main` branch.

## Code standards

- Follow standard Python and PySpark practices.
- Keep SQL readable and formatted consistently.
- Add documentation when introducing new functionality.
- Do not commit credentials, API keys, AWS access keys, or other secrets.

## Pull requests

Pull requests should clearly explain:
- What was changed.
- Why the change was necessary.
- How the change was tested.

Large architectural changes should be discussed in an issue before implementation.

## Code of Conduct

By participating in this repository, you agree to follow the repository's Code of Conduct.
