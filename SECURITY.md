# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please do not
create a public GitHub issue.

Instead, report the issue privately to the repository maintainer.

Please include:

- A description of the vulnerability
- The affected file, component, or functionality
- Steps to reproduce the issue
- The potential impact
- Any suggested remediation, if available

## Sensitive Information

Please do not include passwords, API keys, AWS credentials, access tokens,
or other sensitive information in GitHub issues, pull requests, or commits.

If you accidentally expose credentials, revoke or rotate them immediately.

## Scope

This policy applies to security vulnerabilities in the code and configuration
contained in this repository.
